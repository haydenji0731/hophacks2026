Sherpa icon set. Compass is the primary Chrome toolbar and store mark.

PNG payloads: `icon16.png.b64` and `icon32.png.b64` (the extension loads these even before you decode). Named marks are SVG: `compass.svg`, `cairn.svg`, `signpost.svg`, `tent.svg`, `ridge.svg`.

From this folder run `bash decode.sh` if you want PNG files at `icon16`–`icon128` for `manifest.json`.
